# LLM Demo：Kaggle 大模型部署、量化推理与 GUI-Agent 学习项目

本项目用于系统学习大模型工程化能力，重点围绕 **Kaggle 双 T4 GPU 环境**完成模型部署、量化推理、性能评测与 GUI-Agent 链路验证。

## 项目目标

- 搭建本地与 Kaggle 测试环境，完成 Open-AutoGLM(9B) 与 emotion2vec（语音情绪识别）的部署和运行验证。
- 基于 llama.cpp 与 vLLM 开展量化对比测试，覆盖推理速度、资源占用、效果精度三大维度。
- 完成 GUI-Agent 方案验证，打通远端 Agent 与本地 GUI 调用链路，实现基础界面自动化交互。
- 基于双 T4 GPU 练习大模型部署、量化与推理优化，沉淀标准化调优流程。
- 输出部署测试文档与两类场景技术选型参考，为后续业务落地提供依据。

1. 先阅读 `docs/学习计划.md`，建立整体知识框架。

## 面向岗位的升级方向

如果目标是应聘移动端 AI 应用研发岗位，本项目不应停留在模型部署实验层面。后续需要补齐移动端 App、流式对话、多轮上下文、弱网缓存、模型路由、端侧量化推理和性能稳定性报告。详细升级路线见 [`docs/Kaggle部署量化与Agent验证计划.md`](docs/Kaggle部署量化与Agent验证计划.md) 的“面向移动端 AI 应用岗位的项目升级计划”章节。


## Kaggle Notebook 实施方式

后续建议把每个阶段都落到一个可复现的 Kaggle Notebook：先完成环境检查与模型缓存，再分别验证 Open-AutoGLM(9B)、emotion2vec、llama.cpp、vLLM 和 GUI-Agent 链路，最后汇总成对岗位有说服力的部署报告、量化报告和移动端 AI 应用方案。
